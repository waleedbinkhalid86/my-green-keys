# My Green Keys 🌱

> Learn to type. Help the planet.

A daily learning platform for kids aged 6–14. Combines typing lessons, math + eco micro-lessons (Brain Sprint), and parent-set daily challenges (Habit Quest) into one habit-building experience.

**Live at:** [mygreenkeys.com](https://mygreenkeys.com)

## What it does

- ⌨️ **Typing lessons** — Build real keyboard skills, lesson by lesson
- 🧮 **Brain Sprint** — Quick math sprints and eco lessons
- 🎯 **Habit Quest** — Daily challenges parents set, kids complete
- 🦊 **Ranger system** — XP, streaks, badges, virtual eco garden
- 🎮 **Games** — Typing games for engagement
- 👨‍👩‍👧 **Parent dashboard** — Track children, custom lessons, habit quests
- 🏫 **Teacher dashboard** — Class codes, enrollment, student progress
- 🔐 **Kid-friendly login** — 6-character code, no email, no password

## Tech stack

- **Framework:** Next.js 15 (App Router) + TypeScript
- **Styling:** Tailwind CSS + inline styles, Forest Canopy palette
- **Backend:** Supabase (Postgres, Auth, RLS, Storage)
- **Hosting:** Vercel
- **Payments:** Paddle (disabled while `ALL_FREE` is on in `src/lib/access.ts`)
- **Compliance:** COPPA-aware, GDPR-aware
